# OfficeCLI

使用 BlackRain 内置的 `OfficeCLI` 处理 `docx`、`xlsx`、`pptx` 文档。

## 什么时候用

- 生成或修改 Word、Excel、PowerPoint 文件
- 需要渲染预览、导出 HTML / PNG、检查文档结构
- 需要把结构化数据落成办公交付物

## 默认原则

1. 优先使用内置 `officecli`，不要要求用户安装 Office。
2. 优先走文件级自动化，而不是桌面 UI 点击。
3. 每次生成或修改重要文档后，都应追加一次预览/渲染检查。
4. 如果任务要求真实 Microsoft Office 才能完成的特性，再标记为 Windows COM 兜底候选，而不是默认切路线。

## 推荐工作流

1. 明确目标文件类型：`docx` / `xlsx` / `pptx`
2. 先准备输入数据和模板路径
3. 调用 `officecli` 完成生成、修改、渲染或校验
4. 检查输出结果
5. 如结果不理想，继续修正文档而不是只给口头结论

## 命令约定

- 二进制名：`officecli`
- 由 BlackRain 安装包内置
- 运行时应直接可调用，不依赖用户 PATH 配置

## 输出要求

- 尽量把结果落为可交付文件，而不是只返回一段文字
- 说明生成了什么文件、放在哪里
- 如渲染发现版式问题，继续修复后再交付
