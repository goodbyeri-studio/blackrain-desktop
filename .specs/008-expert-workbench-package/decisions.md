# 工作台包决策

> **状态（2026-07-26）：暂停。** 以下决策不构成当前路线承诺。

## D1：App/Core 是唯一状态写入者

工作台包只能声明期望状态，不得写 App 配置、激活记录或全局环境。

## D2：安装成功不等于任务可执行

包检查、依赖验证和激活记录属于生命周期能力。任务执行由 spec 011 的 Session Orchestrator 消费激活记录，并拥有独立的安全与质量证据。

## D3：激活标识不可变

资源、版本、权限或项目绑定变化时签发新激活标识。既有标识只能更新验证时间，不得改写内容。

## D4：用户项目默认保留

卸载只清理由 App 管理且无其他引用的资源，用户项目和用户管理依赖不删除。

## D5：MVP 只验收 Windows x64

其他平台上的单元测试只提供代码级反馈，不能替代 Windows 安装、运行和卸载验证。
