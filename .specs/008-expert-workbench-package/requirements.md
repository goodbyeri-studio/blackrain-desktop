# 工作台包需求

> **状态（2026-07-26）：暂停。** 工作台包资产和既有代码保留，但不进入当前 P0/P1，不新增生命周期、市场或执行能力。恢复必须由新的产品决策和 spec 明确授权。

## 目标

BlackRain 工作台包必须可声明、检查、安装、激活、升级、回滚和卸载，并能在不依赖作者电脑偶然状态的前提下复现工具环境。

## 必须满足

1. 包含版本化 Manifest、Skills、插件引用、依赖、权限、任务与验证入口。
2. 第三方制品必须记录来源、版本、校验和、License、安装范围与卸载策略。
3. 只有 App/Core 可以写入安装状态和激活状态；工作台包只声明期望状态。
4. 激活前必须完成包结构、平台、依赖、权限、健康检查与 smoke 验证。
5. 激活记录不得携带明文 secret、任意命令或未经验证的可执行路径。
6. 升级和回滚必须产生新的不可变激活标识，不覆盖既有激活记录。
7. 卸载默认保留用户项目，并清理仅由该包拥有的应用托管资源。
8. Windows x64 是 MVP 唯一发布平台，产品可用性必须以 Windows 实机验证为准。

## 当前边界

仓库已实现 Manifest 检查、Office 官方包的受控安装/健康检查/smoke、激活记录持久化与卸载记录移除。激活后的任务执行由 [spec 011](../011-workbench-session-orchestration/) 消费本 spec 的已验证激活记录；011 尚未实现前，不得把包已安装表述为任务已可执行。
