## 当前代码事实

- Electron 迁移代码包含 main-owned `WebContentsView`、持久 Browser partition、typed preload Browser API 和受限 CDP/OOPIF 路径。
- 代码包含 AX snapshot、短期 ref、带 deadline/state/两帧稳定检查的 role/name locator、click/hover/type/press/scroll、viewport/full-page screenshot、主动用户输入抢占和 turn 结束释放逻辑及相应测试。
- selector runtime 位于当前 page/OOPIF 的 CDP isolated world，只维护语义 DOM revision；main 合并增量 AX event，并在 revision 或 generation 变化时刷新/失效。每个 owner 普通 live 预算为 8，额外后台页 frozen/suspended，显示或工具操作前恢复。
- main-owned 敏感动作确认覆盖语义 click 和 Enter/Space 键盘激活；一次性下载授权/实际保存和用户 file chooser 已有合成站点 E2E。下载待确认状态按 tab 替换并由 60 秒 timer 清理；这些证据不等同于真实站点或人工产品验收。
- Browser session state v2 已保存 origin/claim/handoff/deliverable、导航条目、reload policy 和 profile 引用，并兼容 v1；App restart E2E 已证明同 tab id、持久 partition 和 URL reload，未承诺 JS heap/表单/滚动位置。
- App Server 审批/requestUserInput 已通过 main-owned 一次性 broker 接入现有 UI 事件流；响应绑定 workspace/request id，取消、超时、退出和重启后失效。Windows graceful deadline 后使用 `taskkill /T /F`，当前测试已实际证明后代进程被回收。
- fixture runtime 组合测试已覆盖 thread/resume、活跃 turn、app-server `$/cancelRequest`、取消后旧审批响应失效、turn/interrupt、turn/completed、Browser 控制释放，以及模拟 suspend/resume 后原 thread ownership 恢复并可继续 start turn；在线真实模型矩阵仍单独验收。
- Electron main 已绑定 `powerMonitor.suspend/resume`：睡眠前等待启动过程、快照 thread/workspace/cwd ownership，停止此前运行的 App Server/MCP transport、使 pending request/grant 失效、释放控制并冻结页面；唤醒后重启此前运行的 runtime、逐个恢复原 thread subscription/Browser registration、重建 CDP observer，并按 visibility/工作集预算恢复页面。当前自动化只模拟同一生产协调器，不代表真实系统睡眠。
- 自有 Browser MCP adapter/client/transport 包含窄类型工具、可信 `_meta` 路由、framing、capability token、session/turn/generation handshake、hash、License 和打包接点；app-server 启动参数将 `BLACKRAIN_BROWSER_*` 从 agent shell 子进程环境排除。
- 标准 stdio MCP 接缝、真实模型 screenshot 纵向切片与 package 已升级为本轮 `RUN_PASS`/`PACKAGE_PASS`；code-mode seam gate 以“V8 可执行/取消/清理，但不可加载 Node 模块”为成功合同，V8 直载仍为已否决方案。完整生命周期/敏感动作矩阵和 Windows 产品验收尚未通过。
