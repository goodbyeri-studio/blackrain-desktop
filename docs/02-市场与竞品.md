# 02 市场与竞品

> 本文按 2026-07-12 的产品定位重构。厂商功能变化很快，竞品能力以其官方页面和实测为准，不把宣传口径当作完成度证据。

## BlackRain 不参加“通用 Agent 军备竞赛”

国内桌面 Agent 已快速拥挤：WorkBuddy、QoderWork、Kimi Work、扣子等都在覆盖本地文件、浏览器、文档表格、多 Agent、Skills/MCP 和办公交付。

因此，以下能力已经或正在成为入场券，而不是长期护城河：

- 国产模型
- 多模型选择
- 本地文件访问
- 浏览器自动化
- Word / Excel / PPT / PDF
- Skills / MCP
- 多 Agent 协作
- 桌面安装包

如果 BlackRain 以“功能更多的通用办公 Agent”进入市场，就会直接面对大厂的免费、流量、模型和生态优势，胜率极低。

## 真正的市场：专业数字工作环境

市场中现有四类产品：

| 类别 | 用户得到什么 | 主要缺口 |
|---|---|---|
| 通用 Agent | 一个聪明的助手 | 环境是空的，垂类深度有限 |
| 垂直 SaaS | 固定场景的成品软件 | 流程写死，长尾定制成本高 |
| RPA / 自动化平台 | 可编排的规则和连接器 | 脆、搭建门槛高、缺少专家方法 |
| 课程/咨询 | 专家知识和建议 | 不能直接执行，难规模化复制 |

BlackRain 提供第五种商品：

> **可安装、可执行、可验证、可升级的专家数字工作环境。**

它把通用 Agent 的灵活性、垂直 SaaS 的专业性、RPA 的执行力和专家咨询的方法论组合到工作台里。

## 竞争单位不同

大厂通用 Agent 的竞争单位通常是“一个产品覆盖多少场景”。

BlackRain 的竞争单位是“多快生产出一套真正可用的垂类工作台”。

```text
大厂路线：一个通用 Agent → 尽可能覆盖所有人
BlackRain：一个通用底座 → 大量专家工作台 → 分别服务长尾领域
```

这不是和大厂比谁更全，而是利用统一底座聚合大厂不愿逐个深挖的碎片化市场。

## 为什么长尾垂类成立

很多行业已经高度电脑化，却没有自己的强 Agent：

- 股票和行业研究
- GIS 和地图数据处理
- CAD / BIM / 工程资料
- 招投标和合同资料
- 跨境电商运营
- 学术研究和统计分析
- 专利与知识产权检索
- 视频、字幕和素材生产
- 企业内部遗留系统和 Excel 流程

单个领域可能不够支撑一家大厂的独立产品线，但它们共享大量底层能力：文件、浏览器、脚本、Office、数据处理、权限、模型、安装、更新和验证。BlackRain 用统一 Core 摊薄底座成本，再由领域专家提供上层差异。

## 与主要竞品的错位

### WorkBuddy / Kimi Work / QoderWork / 扣子

这些产品证明了“Agent 进入桌面工作”是大趋势，也意味着桌面执行本身不能作为 BlackRain 的独占卖点。

BlackRain 不应复制它们的通用任务清单，而应允许专家把它们不会逐个深做的环境封装出来：专业软件、项目目录、数据连接、行业模板、验证规则和长期维护。

### Coze / Dify / n8n

它们擅长编排 API、工作流和 Bot。BlackRain 的差异是工作台不仅描述流程，还能携带本地运行环境、专业工具、目录、模板、验证和恢复策略。

### 垂直 SaaS

垂直 SaaS 在高频确定流程上更稳定。BlackRain 不必替代所有 SaaS，而是：

- 连接已有 SaaS 和本地软件
- 覆盖 SaaS 没有产品化的长尾流程
- 让专家快速组合新岗位环境
- 在确定性要求高的步骤调用脚本和验证程序

### Codex / Claude Code

它们不是需要击败的竞品，而是“专业环境 + Agent”范式在程序开发领域的成功样板和上游参考。

BlackRain 的 CODE surface 也不是主要市场战场，而是平台内置的软件开发专业环境。

## 真正的差异化

### 1. 工作台包与环境复现

能否把专家的工具、依赖、目录、模板和配置可靠安装到另一台 Windows 电脑，是第一道硬门槛。

### 2. 专家资产供给

真正稀缺的不是 Prompt 数量，而是来自真实高手、经过真实任务打磨的工具组合、流程和检查习惯。

### 3. 垂类验证

工作台必须证明它安装正确、工具可用、标准任务能完成、结果可检查。验证程序和真实失败数据会形成持续资产。

### 4. 长尾聚合效率

同一个 Core 复用到多个小市场，让过去不值得单独开发的软件领域也能拥有专业 Agent。

### 5. 专家经济

市场阶段让专家出售可维护的工作台，而不是上传同质化聊天机器人。完整设计见 [06 专家经济与工作台市场](06-市场与创作者经济.md)。

## “不锁模型”的新位置

模型中立仍然有价值，但它是平台能力，不是主叙事。

用户最终购买的是某个工作台能否可靠完成任务。模型选择应该服务于成本、质量、合规和可替换性，而不是让普通用户承担复杂选型。

## 黑马路径

BlackRain 成为黑马的方式不是先获得最多用户，而是：

1. 用 Office 参考工作台跑通工作台生命周期。
2. 找到一个大厂通用 Agent 做不深的垂类。
3. 和 3～5 位真实高手共同封装工作环境。
4. 用真实用户任务把方法固化成 Skills、脚本和验证规则。
5. 在该领域形成“这个活就装这个工作台”的心智。
6. 复用底座进入第二、第三个长尾垂类。

## 结论

BlackRain 不是“中国又一个桌面 Agent”，而是：

> **垂类 Agent 的生产、运行与分发平台。**

大厂负责把通用 Agent 做成基础设施；BlackRain 的机会是在基础设施之上，把专家电脑变成可安装、可交易的专业能力。
