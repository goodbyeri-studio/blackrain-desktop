# 01 产品愿景

## 一句话定义

BlackRain 是一个由 AI 驱动的垂类工作环境平台：

> **把领域高手电脑里的工具、环境和工作流封装成可安装的工作台，让普通人快速获得专业级生产能力。**

它不是“再做一个通用办公 Agent”，也不以正面击败大厂通用助手为目标。BlackRain 提供一个可复用底座，让每个高度电脑化的领域都能快速形成自己的“Codex”。

## Codex 真正证明了什么

Codex、Claude Code 降低软件开发门槛，不只是因为模型会写代码，而是因为 Agent 进入了一个成熟的专业环境：

- 项目目录和代码仓库
- 编译器、运行时和依赖
- Git、CLI、测试和调试工具
- README、AGENTS.md、Skills 和工程规范
- 可执行、可观察、可验证的反馈循环

因此，编码 Agent 的完整公式是：

```text
强 Agent + 程序员工作环境 + 软件工程方法论
```

BlackRain 的核心推论是：

> 程序开发只是第一个被 Agent 大幅降低门槛的电脑化垂类，同一范式可以复制到股票研究、Office、GIS、CAD、电商运营、学术研究、招投标、视频制作等长尾领域。

## 真问题：高手的电脑无法被普通人继承

一个领域高手的生产力通常不只在脑子里，也沉淀在电脑上：

- 多年筛选出来的宝藏工具
- 配置好的运行环境和账号连接
- 固定的文件夹、命名和项目结构
- 模板、样例、数据源和资料库
- 自动化脚本、快捷命令和插件
- 任务顺序、检查习惯和失败处理

过去，这些资产很难传播：教程只能讲，软件只能提供单点功能，咨询只能按时间交付，复制整台电脑又会遇到依赖、License、隐私和版本漂移。

AI 带来的新机会是：普通用户不必先学会整套工具。只要工作环境能够被声明、安装和验证，Agent 就能替用户操作它，并在关键节点解释、询问和交付。

## BlackRain 分发的不是 Prompt，而是专业环境

BlackRain 的最小价值公式是：

```text
Skill（高手的方法）
+ 插件（高手的工具）
+ 环境（高手的电脑配置）
+ 资源（模板、样例、数据连接）
+ 验证（高手的检查习惯）
= 工作台（可安装的专业生产能力）
```

工作台作者不只是程序员，也可以是行业专家、高阶从业者、工具作者或帮助专家完成数字化封装的实施者。

用户购买或安装的核心商品不是散装插件，而是一套已经布置好的专业工作环境。

## 为谁做

| 用户层 | 是谁 | 得到什么 |
|---|---|---|
| 使用者 | 想进入某个领域、但不会搭环境的小白或进阶用户 | 一套可直接使用的专家工作台和 AI 操作者 |
| 领域专家 | 已经拥有成熟工具链和工作方法的人 | 把电脑里的能力资产化、规模化交付 |
| 封装者 | 懂技术、能帮助专家整理环境的人 | 把专家经验转成可安装、可维护的工作台 |
| 团队/企业 | 需要复制标准岗位能力的组织 | 可控、可审计、可版本化的数字岗位环境 |

## 产品层级

对用户的价值台阶是：

> Skill → 插件 → 工作台 → 工作室（OPC 一人公司）

正式架构是：

```text
Skill + 插件 + 环境 + 资源 + 验证 → 工作台 → 工作室
```

- Skill 复制方法。
- 插件复制工具。
- 工作台复制电脑。
- 工作室复制团队。

完整边界见 [04 产品形态](04-产品形态.md)。

## 为什么是现在

1. **Agent 已能操作真实环境。** 文件、命令、浏览器、代码、API 和工具调用已形成闭环。
2. **国产模型已能承担大量执行任务。** BlackRain 可以在国内网络、计费和合规环境下交付。
3. **专业开源工具极其丰富。** 大量领域并不缺能力，缺的是筛选、安装、组合和使用门槛。
4. **大厂会优先做横向高频场景。** 单个长尾垂类不足以让大厂逐一深耕，却可以被同一个工作台底座聚合。
5. **专业环境第一次可以成为商品。** Manifest、运行时、插件、Skills、模板和验证可以共同组成可版本化的工作台包。

## 与大厂的关系

BlackRain 不在以下战场正面竞争：

- 谁拥有最大的模型
- 谁的通用聊天入口用户最多
- 谁免费提供最多横向办公功能
- 谁的编码 Agent 补全速度更快

BlackRain 要争的是另一件事：

> 谁能把领域高手的电脑最快封装成普通人能安装、能使用、能验证的专业工作台。

大厂的通用 Agent、模型和基础工具甚至可以成为工作台的上游能力。BlackRain 的自有资产在上层：专家环境、垂类方法、验证程序、真实任务反馈和供给网络。

## 首批策略

Office 是第一套参考工作台，用于验证底座，不等于最终市场定位。

真正用于市场切入的垂类应满足：

- 日常工作主要发生在电脑上
- 专家工具链碎片化且安装门槛高
- 工作流程高频、重复、可拆解
- 结果能够被检查或部分验证
- 有活跃的专家供给和开源/合法工具资源
- 大厂通用产品难以为它做足够深的定制

股票研究符合“工具和环境丰富”的特征，但涉及数据授权、金融宣传和责任边界，更适合作为候选工作台研究，不应在未完成合规设计前宣传为自动荐股或收益工具。

## 不做什么

- 不把 BlackRain 定义成又一个通用办公助手。
- 不让用户先理解 Codex、Hermes、WORK、CODE 才能使用产品。
- 不把一段 Prompt 或几个 Markdown 文件包装成完整工作台。
- 不承诺安装环境就等于获得专家判断，更不承诺金融收益、医疗结论或法律结果。
- 不为了某个垂类硬 fork Agent 内核；垂类差异落在工作台层。
- 不在单工作台模型尚未跑通前，过早建设庞大的市场和多工作台工作室。

## 成功的样子

用户打开 BlackRain，不是先面对一个空白输入框，而是看到可以安装的专业工作台：

```text
我的工作台
├── Office 办公
├── 软件开发
├── A 股基本面研究
├── 跨境电商选品
└── 安装更多工作台
```

安装后，用户获得一套专家配置好的项目结构、工具、环境、流程和检查规则，并由 AI 帮他操作。

BlackRain 的长期目标不是拥有一个无所不能的 Agent，而是让大量长尾领域都拥有自己的专业 Agent 环境。
