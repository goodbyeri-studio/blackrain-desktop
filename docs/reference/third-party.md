# 第三方来源

第三方代码和资源按各自许可证分发。仓库根目录的 [NOTICE](../../NOTICE) 是归属清单；本页只说明审查规则。

- 新增 npm 包、字体、图标、二进制或代码片段前，记录来源、版本、许可证和 hash。
- MIT/Apache-2.0 组件仍需保留版权和许可证文本。
- AGPL/GPL/BSL 或无许可证内容，在完成单独法律审查前不进入发行包。
- 上游 runtime 作为独立制品锁定和审计，不由 BlackRain 的 MIT 许可证重新授权。
- 生成的 runtime、签名证书、用户数据和测试输出不属于源码提交。

依赖安全公告请使用 [SECURITY.md](../../SECURITY.md) 的私下报告流程，不要在 issue 中粘贴凭据或完整日志。
