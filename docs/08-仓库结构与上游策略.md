# 仓库结构与上游策略

## 目录

```text
apps/desktop/      Tauri 桌面壳
gateway/           CODE 协议转换 sidecar
plugins/           工具与软件适配器
workbenches/       专家工作台包
.specs/            living specs
docs/              战略、架构与运行手册
codex-upstream/    gitignored 的只读上游克隆
```

## 三类代码

| 类型 | 位置 | 规则 |
|---|---|---|
| 产品代码 | `apps/desktop/`、`gateway/` | 日常修改，测试与文档同步 |
| 工作台供给 | `plugins/`、`workbenches/` | 声明来源、License、权限、安装和验证 |
| agent 内核黑盒 | `codex-upstream/` | 所有 surface 统一复用；只读、不改 agent 循环；显式锁定版本并重跑 Windows 矩阵 |

`apps/desktop/` 是 CodexMonitor 的 git subtree。日常改动直接提交在本仓，不随手执行 subtree pull。领域逻辑优先进入 `src-tauri/src/shared/*`，App 与 Daemon 保持薄适配。

## 上游锁

codex 目标锁为 `rust-v0.144.5` / `87db9bc18ba5bc82c1cb4e4381b44f693ee35623`。`scripts/fetch-references.sh` 校验 tag 指向的完整 SHA 后 detached checkout。

版本锁只证明源码身份，不证明 Windows 二进制、协议、GUI 或安装包可用。升级必须更新 references、重新构建，并执行 spec 006/007 的能力与发布验证。
