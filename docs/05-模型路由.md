# 模型路由

## 当前链路

```text
codex app-server
  -> Responses
  -> BlackRain Model Gateway
  -> Chat Completions
  -> new-api 计量
  -> 模型提供商
```

Gateway 服务所有由 codex 发起的模型会话，无论前端呈现为工作台 surface 还是 CODE surface。它负责协议转换、流式事件映射、工具调用转换和上游错误归一化，不负责账号业务、工作台生命周期、会话编排或 UI 状态。

## 配置

App 写入专属 `CODEX_HOME/config.toml`，将 codex 的 `base_url` 指向本地 Gateway。用户已有的 `~/.codex` 不参与。

provider secret 由系统凭据存储保存；配置和日志只保留 provider id、模型 id、路由状态和脱敏错误。

## 账号与计量

平台账号模式通过 new-api 计量。BYOK 的套餐边界、secret 存储和路由规则以 spec 001/002 为准。任何未完成的服务端收敛不得写成已发布能力。

## 发布闸口

- Responses 非流式与流式转换
- 工具调用与多轮消息
- 超时、取消、上游 4xx/5xx 映射
- Gateway 进程崩溃与重启
- Windows 真实模型对话
- 日志脱敏和凭据隔离

当前 `gateway.py` 是零依赖可行性原型，不是生产完成度声明。
