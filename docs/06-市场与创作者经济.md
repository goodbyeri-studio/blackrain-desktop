# 06 暂缓路线：工作台、市场与 OPC

> **状态（2026-07-26）**：整篇对应方向暂停。本文只定义暂停边界，不构成 post-MVP 承诺或实现清单。

## 暂停内容

- 专家工作台包和环境复现
- Office 参考工作台
- 工作台安装、激活、升级、回滚和卸载
- Session Orchestrator 与 workbench surface
- 插件目录、工作台市场和专家结算
- 工作室、OPC 一人公司、多岗位和多 Agent 编排

相关代码、包、specs 和研究资料作为冻结资产保留。维护者可以修复影响主线构建、安全或 License 的问题，但不得在没有新决策的情况下继续产品化、扩充目录或把它们接回主导航。

## 为什么暂停

BlackRain 当前最重要的问题不是供给市场，而是先把开源 `codex-rs` 变成完整、可靠的桌面产品。Electron 迁移、in-app browser、核心 Codex 工作流、Windows 安装与恢复未完成前，继续扩张工作台和 OPC 会分散运行时、产品和验证资源。

## 资产处理规则

- `workbenches/` 与相关 plugins 不删除，但标记暂停。
- spec 008/011 保留已经验证的历史实现事实，并在顶部标记暂停。
- 当前 P0 不新增 workbench 专属 thread、surface、配置写入者或发布资源。
- OPC UA 适配器如果未来被 Browser/Codex 主线明确需要，可作为单一工具重新评估；这不等于恢复 OPC 公司路线。

## 重新启动条件

只有同时满足以下条件，才讨论恢复：

1. Electron Windows 制品完成安装、升级和恢复闭环。
2. 核心 Codex App 能力差距达到明确阶段目标。
3. in-app browser 在真实任务中稳定可用。
4. 有新的用户证据证明工作台或 OPC 比继续补齐 Codex 产品更优先。
5. 新 spec 重新确认产品入口、运行时所有权、安全、License 和验证矩阵。

旧的市场规模、创作者分成和 OPC 蓝图不能自动成为恢复依据。
