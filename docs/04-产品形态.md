# 04 产品形态

> **本文是产品形态和优先级的唯一真源。** 运行时进程看 [09](09-运行时架构与里程碑.md)，Electron 迁移看 [spec 012](../.specs/012-electron-shell-migration/)，能力补齐看 [spec 013](../.specs/013-codex-app-capability-parity/)。

## 产品第一主语

BlackRain 是 Codex-first 桌面 App。

用户打开产品后直接进入项目、thread 和任务执行，而不是先选择工作台、角色或 agent 内核。产品围绕一个持续可恢复的 Codex 工作流组织：

```text
项目
  -> thread / turn
  -> 文件、终端、Git、diff、审批、Browser
  -> 结果、恢复和继续工作
```

## 核心体验

### 项目与 thread

- 打开本地项目或工作目录
- 创建、切换、搜索、归档和恢复 thread
- 流式展示推理状态、工具活动、审批和结果
- 保持草稿、队列、停止和错误恢复可预测

### 工程 surface

- 文件与变更
- diff 与 review
- 终端和命令执行
- Git 分支、提交和 PR 工作流
- 上下文、模型和权限设置

### In-app Browser

Browser 是 P0 产品 surface，不是外链按钮或隐藏自动化：

- 页面在 App 内可见
- 登录态持久且与 App 权限隔离
- agent 可执行受控导航和页面操作
- 用户可随时接管并归还控制
- 截图、下载、权限和异常都有可见状态
- 页面和 thread 可以关联，但网页 secret 不进入模型上下文

## 优先级

### P0：并列推进

1. **Electron 全量迁移**：建立 main/preload/renderer/daemon 目标宿主并最终删除 Tauri runtime。
2. **Codex App 能力补齐**：建立能力账本，先完成 in-app browser 纵向闭环。

### P1：P0 闭环后的产品补齐

- 核心项目/thread/审批/diff/终端体验缺口
- 桌面通知、快捷键、更新和恢复
- 性能、诊断、可访问性和 Windows 交付质量
- 当前锁定 `codex-rs` 新能力的产品化

P1 的具体排序必须来自能力矩阵，不按旧工作台路线自动继承。

### 暂停

- 工作台 Manifest、安装、激活、升级与卸载
- Session Orchestrator 与 workbench surface
- Office 参考工作台
- 插件市场、专家市场与创作者经济
- OPC/工作室、多角色和多 Agent 公司编排

“暂停”表示代码与文档资产可以保留，但不进入当前导航、发布承诺、里程碑或自然扩建。重新启动必须有新决策。

## 内核与宿主边界

| 能力 | 所有者 |
|---|---|
| agent loop、thread、turn、工具调用、审批协议 | 原装 `codex-rs` / app-server |
| app-server 监管、项目/文件/Git/终端领域逻辑 | Rust daemon/shared core |
| 窗口、Browser、权限、下载、更新、系统集成 | Electron main |
| 最小特权桥 | preload |
| 用户界面和前端交互状态 | React renderer |
| 非 Responses 模型协议适配 | 可选 Gateway sidecar |

不得因为 UI 需要而修改 agent 内核；不得因为迁移方便而把 Rust 领域逻辑散落进 main/renderer。

## “复刻 Codex App”的含义

允许：

- 研究公开文档与合法可观察的产品行为
- 对齐信息架构、工作流、反馈节奏和能力合同
- 使用自有实现、品牌、设计系统和宽松许可证依赖

不允许：

- 复制或反编译闭源代码、bundle 和协议密钥
- 提取并复用专有图标 path、字体或其他资源
- 暗示 BlackRain 是 OpenAI 官方客户端
- 用未验证的相似界面宣称功能一致

## 当前水位

- 当前实现：Tauri + React + Rust，CodexMonitor 衍生壳。
- 已有资产：CODE UI、app-server 接缝、daemon/shared core、部分项目/Git/终端能力、Gateway 原型。
- 尚未实现：Electron 正式工程、Electron IPC、WebContentsView Browser、Browser 工具合同和 Windows Electron 制品。
- 暂停资产：workbenches、相关 plugins、spec 008/011 和 OPC/市场文档。
