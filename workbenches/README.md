# workbenches —— 工作台内容

这里存放 2049 App 的核心产出:**工作台**及其技能。

一个工作台是「一间布置好的房间」,技术上由纯文本/Markdown 构成,不需要写代码:

```
workbenches/
└── <工作台名>/
    ├── AGENTS.md        # 人设与规矩（这个工作台里 agent 是谁、守什么规矩）
    ├── skills/          # 一组技能，每个是一份 SKILL.md
    │   └── <技能名>/
    │       └── SKILL.md
    ├── templates/       # 模板（大纲、人物卡等）
    └── README.md        # 这个工作台是什么、给谁用、能干嘛
```

设计理念见 [docs/04-工作台与插件](../docs/04-工作台与插件.md),尤其是「带护栏的发挥」这一核心产品手艺。
